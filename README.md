# Morning Market Intelligence

An automated AI news monitoring workflow built with **n8n** that collects recent AI-related news, filters relevant stories, and delivers a daily digest through Telegram alongside a startup-focused briefing generated by Google Gemini and sent through Gmail.

## Overview

Keeping up with AI developments takes time. This workflow automates the process of collecting news from multiple RSS feeds, filtering articles based on keywords and publication dates, and organizing the results into two useful outputs.

- **Telegram:** Sends a digest of selected news headlines with article links.
- **Gmail + Google Gemini:** Generates an HTML briefing explaining the business impact of each story, including opportunities, risks, and practical actions for a startup.

## Workflow

The workflow follows this sequence:

1. **Schedule Trigger** — Starts the workflow daily at 7:00 AM, based on the n8n instance's timezone.
2. **Search News** — Defines the RSS feeds used to collect AI-related news.
3. **Split Out** — Separates the feed configuration into individual items.
4. **RSS Read** — Retrieves articles from the configured feeds.
5. **Clean News** — Processes the retrieved news data.
6. **Filter** — Keeps articles within the configured date range that match at least one target keyword in the title.
7. **Sort** — Orders the selected articles by publication date, newest first.
8. **Limit** — Restricts the number of stories to the configured maximum.
9. **Aggregate** — Combines the selected stories for the output branches.
10. **Telegram** — Sends the selected headlines and article links.
11. **Google Gemini** — Generates a startup-oriented briefing in HTML.
12. **Gmail** — Sends the generated briefing by email.

## News Sources

The workflow is configured to use these RSS feeds:

- [AI Central Tools](https://aicentraltools.com/news/feed/)
- [Hacker News — AI search](https://hnrss.org/newest?q=AI)

Feed availability and formats may change over time.

## Filtering and Configuration

The workflow currently uses the following settings:

| Setting | Value |
|---|---|
| Schedule | Daily at 7:00 AM |
| Maximum stories | 5 |
| Lookback period | 4 days |
| Keyword matching | Article titles |
| Sorting | Newest first |

### Target Keywords

The current keyword list is:

- `llm`
- `Openai`
- `machine learning`
- `agent`
- `google`
- `startup`
- `model`

These keywords determine which articles pass the title-based filter. An article can be relevant to AI and still be excluded if its title does not match the configured keywords.

## AI-Generated Startup Briefing

The workflow uses Google Gemini to turn the selected stories into a practical briefing for a startup.

Instead of simply repeating headlines, the prompt asks Gemini to explain:

- **Business impact:** Why each story matters to the startup.
- **Opportunities:** Potential ways the startup could benefit.
- **Risks:** Relevant challenges or threats.
- **Practical actions:** Steps the startup could consider taking.

The generated response uses HTML with inline CSS and is sent through Gmail.

### Gemini Prompt

The full prompt is available in [`prompts/gemini-startup-briefing.md`](prompts/gemini-startup-briefing.md).

## Requirements

Before running the workflow, make sure you have:

- An n8n instance.
- Access to the configured RSS feeds.
- A Telegram bot and the required Telegram credentials.
- Google Gemini API credentials configured in n8n.
- Gmail credentials configured in n8n.
- The required nodes and connections configured correctly.

Credential setup and authorization must be completed in your own n8n instance.

## Setup

1. Download or clone this repository.
2. Open your n8n instance.
3. Import the workflow JSON file.
4. Configure the Telegram, Google Gemini, and Gmail credentials.
5. Review the RSS feed URLs, target keywords, date range, and maximum story count.
6. Verify the recipient and Telegram destination in your own configuration.
7. Execute the workflow manually and inspect both output branches.
8. Confirm that the Telegram digest and Gmail briefing are generated as expected.
9. Activate the workflow when you are ready to run it on schedule.

**Important:** The provided workflow export is currently marked inactive. Importing it does not mean scheduled execution is already running.

## Limitations

- News selection depends on the availability and structure of the RSS feeds.
- Filtering is based on configured keywords in article titles, so some relevant stories may be missed.
- The maximum number of stories is limited by the workflow configuration.
- Gemini-generated analysis may be incomplete or inaccurate and should be reviewed before making business decisions.
- Email and Telegram delivery depend on valid credentials, permissions, and destination settings.
- The exported workflow does not contain execution history, so no verified execution count is reported here.

## Security

- Do not commit API keys, OAuth tokens, bot tokens, or other credentials.
- Avoid publishing private email addresses, Telegram chat IDs, or credential identifiers.
- Store credentials using n8n's credential management rather than hardcoding secrets into workflow data.
- Review exported workflow JSON files before publishing them publicly.
